
# AttendX-Test-Scripts

## Project Description
This repository contains sample automated tests
for a student attendance application.

## Files

1. login_test.py
   - Tests valid login.
   - Tests invalid password.
   - Tests empty login fields.

2. attendance_test.py
   - Tests marking attendance as Present.
   - Tests marking attendance as Absent.
   - Tests empty student ID validation.

## Requirements
- Python 3
- Git
- VS Code

## Run Tests

python login_test.py
python attendance_test.py

## Purpose
Git and GitHub are used to track changes,
maintain commit history and share test scripts.
